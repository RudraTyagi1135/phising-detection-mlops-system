The Correct Future Workflow

For a new project, do:

git init

dvc init

dvc remote add -d dagshub https://dagshub.com/<owner>/<repo>.dvc

dvc remote modify dagshub auth basic

dvc remote modify dagshub user <username>

dvc remote modify dagshub password <token> --local

Then:

dvc add data.csv

dvc push

git add data.csv.dvc

git commit -m "Track dataset"

git push
